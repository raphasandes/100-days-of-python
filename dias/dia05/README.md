# Dia 05 — Laços de repetição (`for`)

## 📚 O que aprendi

- Como utilizar o `for`.
- Como percorrer listas.
- Como funciona o `range()`.
- Como prever a execução de um laço.

## 💻 Exercícios

- Percorrer listas.
- Prever a saída de programas.
- Entender a variável de controle.

## 💼 Aplicação profissional

Laços de repetição podem ser utilizados para percorrer grandes bases de dados, automatizar relatórios, validar informações e processar milhares de registros sem repetir código manualmente.

## 📝 Reflexão

Hoje compreendi que o `for` não só repete código. Ele percorre uma sequência de elementos até que ela termine.
