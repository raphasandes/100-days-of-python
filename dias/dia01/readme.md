Antes desta aula eu imaginava que programar significava escrever comandos complexos.

---

# Conceitos importantes

## Variável

Uma variável é um espaço da memória utilizado para armazenar informações.

Exemplo:

```python
nome = "Raphael"
```

---

## String

Representa textos.

```python
nome = "Raphael"
```

Tipo:

```python
str
```

---

## Inteiro

Representa números inteiros.

```python
idade = 34
```

Tipo:

```python
int
```

---

## print()

Utilizado para mostrar informações na tela.

```python
print(nome)
```
