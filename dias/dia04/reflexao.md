# Reflexão — Dia 04

Nesta aula revisei os fundamentos estudados até aqui.

A revisão foi importante para perceber que variáveis, listas e condicionais podem ser combinadas para formar programas mais completos.

Também comecei a desenvolver a habilidade de ler um código e prever seu resultado sem precisar executá-lo imediatamente.

Percebi que já consigo compreender melhor a lógica geral dos programas, embora ainda precise praticar para tornar esse raciocínio mais rápido e natural.

A revisão preparou a base para o estudo dos laços de repetição e para a primeira prova do curso.
