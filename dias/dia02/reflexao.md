# Reflexão — Dia 02

Nesta aula aprendi a criar programas capazes de tomar decisões.

O conteúdo se aproximou bastante de regras utilizadas no cotidiano profissional, como verificar o alcance de metas ou a elegibilidade para determinado benefício.

Um ponto importante foi compreender a diferença entre `=` e `==`. O primeiro atribui um valor, enquanto o segundo realiza uma comparação.

Também percebi que a indentação não é apenas uma questão visual. Ela define quais comandos pertencem a cada condição.

Agora consigo construir programas simples que apresentam resultados diferentes conforme os valores analisados.
