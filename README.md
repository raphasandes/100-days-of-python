# 🐍 100 Days of Python

Desafio pessoal de estudo de Python por 100 dias, com registro de aprendizado!

Este repositório documenta minha evolução, desde os fundamentos até projetos completos voltados para automação, análise de dados e inteligência artificial.

## 🎯 Objetivos

- Aprender Python de forma prática.
- Construir um portfólio técnico.
- Desenvolver projetos reais.
- Aprender Git e GitHub.
- Registrar minha evolução como desenvolvedor.

## 📁 Estrutura

- `dias/` → registros de estudo e exercícios.
- `projetos/` → projetos completos.
- `desafios/` → desafios extras.
- `recursos/` → materiais de apoio.
